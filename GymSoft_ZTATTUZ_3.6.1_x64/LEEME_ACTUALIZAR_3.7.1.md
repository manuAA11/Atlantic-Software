# Atlantic Gym 3.7.1 · Prueba de actualización remota

Atlantic Gym es una sola aplicación para todas las instalaciones, disponible para Windows de 32 y 64 bits.

- Tema Minimal disponible en Configuración → Apariencia. El tema Oscuro se conserva.
- Iconos redondos, controles redondeados y textos integrados al fondo azul.
- Inicio de sesión con la identidad de Atlantic Gym.
- Aviso visible de nuevas versiones y acceso al proceso de actualización desde la aplicación.

Esta entrega es una versión de prueba, NO FINAL. Conserva los identificadores y las carpetas de instalación, el proveedor de datos, las sesiones y la configuración del lector y la puerta. No aplica cambios a las bases de datos de clientes.

La actualización es opcional: se descarga desde la aplicación, comprueba su tamaño y SHA256 y respalda los datos locales antes de abrir el instalador. Cierra Recepción y las otras ventanas de Atlantic Gym antes de actualizar desde Administración. Windows puede solicitar confirmación para el instalador o el controlador del lector. Después de instalar, vuelve a abrir Atlantic Gym y comprueba que muestre la versión 3.7.1.

Los servicios externos y el lector/relé físico conservan sus requisitos de aceptación. El instalador de 32 bits requiere Windows de 32 bits; su instalación física aún debe comprobarse allí.
