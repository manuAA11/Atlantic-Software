# Gym soft Comercial 3.4.3

## Actualización

1. Cierra Gym soft y extrae `GymSoft_Comercial_3.4.3_COMPLETO.zip` en una carpeta nueva.
2. Ejecuta `CREAR_INSTALADORES.bat` en Windows.
3. Mantén el escritorio visible y desbloqueado durante las pruebas gráficas.
4. Instala `salida/GymSoft_Instalar_o_Actualizar_3.4.3.exe` para Administración y Recepción.
5. Instala `salida/GymSoft_Propietario_PRIVADO_3.4.3.exe` solamente en tu computador.

La compilación se detiene si una prueba falla. No ejecutes SQL sobre una base comercial existente.

## Qué cambia

- El Dashboard ya no muestra **Más de 30 días**. Los cuatro rangos prioritarios ocupan la fila disponible y el bloque de tiqueteras sube sin dejar una tarjeta aislada.
- Al maximizar o restaurar, la aplicación conserva la vista anterior durante la animación y aplica la distribución final en una sola pasada. No se muestran tarjetas partidas ni barras que aparecen y desaparecen mientras Windows cambia el tamaño.
- El contenido largo sigue pudiendo desplazarse, pero las barras sólo aparecen cuando hacen falta. Las tablas y listas conservan su desplazamiento independiente.
- No se modifican datos, permisos ni la base de Supabase.

## Comprobación manual recomendada

Abre el Dashboard, maximiza y restaura la ventana varias veces y confirma que la vista aparece completa después de cada cambio. Comprueba que las cuatro tarjetas de membresías permanecen juntas y que las tiqueteras quedan inmediatamente debajo. En una ventana normal, reduce el tamaño hasta el mínimo permitido y verifica que el contenido se consulta con la barra sólo cuando excede la altura disponible.
