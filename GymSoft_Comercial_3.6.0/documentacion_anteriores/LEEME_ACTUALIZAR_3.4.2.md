# Gym soft Comercial 3.4.2

## Actualización

1. Cierra Gym soft y extrae `GymSoft_Comercial_3.4.2_COMPLETO.zip` en una carpeta nueva.
2. Ejecuta `CREAR_INSTALADORES.bat` en Windows.
3. Mantén el escritorio visible y desbloqueado mientras se ejecutan las pruebas gráficas.
4. Instala `salida/GymSoft_Instalar_o_Actualizar_3.4.2.exe`.
5. Instala `salida/GymSoft_Propietario_PRIVADO_3.4.2.exe` solamente en tu computador.

La compilación se detiene si una prueba falla. No ejecutes SQL sobre una base comercial existente.

## Correcciones de esta versión

- El cambio entre ventana normal y maximizada se publica únicamente cuando termina la transición de Windows. Las tarjetas no se muestran en estados intermedios ni se redibujan durante el arrastre.
- La distribución normal y la maximizada se conservan como perfiles estables. El desplazamiento se limita al contenido que realmente excede el área visible.
- Una interrupción temporal de Internet durante la comprobación de licencia ya no cierra el programa. Se muestra un aviso profesional una sola vez y se reintenta automáticamente.
- Si falla el inicio de sesión, **Reintentar** abre directamente el formulario de correo y contraseña, sin volver a preguntar si la persona tiene cuenta.

La huella sigue siendo opcional, Recepción no incluye Dashboard, y se conservan pagos editables, tiqueteras, gastos, estadísticas y el editor del propietario.

## Comprobación manual recomendada

Prueba iniciar sesión con una contraseña incorrecta y pulsa **Reintentar**. Después cambia entre ventana normal y maximizada. Desconecta brevemente la red: la aplicación debe permanecer abierta y volver a comprobar la licencia automáticamente.
