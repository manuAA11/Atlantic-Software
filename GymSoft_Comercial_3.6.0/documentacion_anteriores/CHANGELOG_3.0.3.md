# Gym soft · Correcciones y paridad 3.0.3

- Los accesos directos de Administración y Recepción usan el icono embebido del `.exe` y el instalador copia también `icono.ico`.
- Se mantiene visible la ventana de inicio durante la autenticación.
- Finanzas permite abrir directamente la corrección/anulación de pagos y conserva la auditoría.
- Recepción conserva **Crear gasto** con validación del servidor y registro del usuario responsable.
- Se incluyen clientes editables, pagos, gastos, tienda, rutinas, clases, control de entrada, marketing, importación/exportación, respaldos, auditoría y sincronización en vivo.

El esquema de Supabase sigue siendo `3.0.0`; no se debe volver a ejecutar la instalación completa por estos cambios de aplicación.
