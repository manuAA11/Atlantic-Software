# Atlantic Gym 3.7.0 — beta de plataforma

Instalar o actualizar conserva los directorios y los IDs históricos. La actualización
incluye servicios compartidos de hardware y recuperación de sesiones. Core y el
actualizador permanecen sujetos a validación y al piloto autorizado de ZTATTUZ.
No es una entrega final hasta completar las aceptaciones de release_readiness.json.
No modificar condiciones ni contenido del runtime original DigitalPersona.
Los servicios que requieren servidor siguen necesitando conexión. Una caída de
Core no cierra la aplicación ni implica licencia suspendida.
